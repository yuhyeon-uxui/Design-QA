# 🤖 진성(Real) AI QA 리포트 구현 계획 (Implementation Plan)

## 📌 개요
현재 정적 JSON 파일로 데모만 제공되는 'AI QA 진단 리포트'를 실제 Firebase DB의 데이터와 **Gemini API**를 연동하여 실시간 분석이 가능한 진성 AI 기능으로 고도화합니다.

## 🎯 핵심 원칙 (사람과 AI의 역할 분담)
1. **숫자는 시스템이 계산 (Code)**: 전체 이슈 건수, 해결률, 재오픈 건수 등 명확한 수치는 프론트엔드/백엔드 로직으로 계산합니다. AI의 할루시네이션(환각)을 방지합니다.
2. **의미는 AI가 정리 (Gemini)**: QA 이슈 텍스트, 재오픈 사유, 코멘트 등을 분석하여 '공통 패턴'을 묶고, 회의에서 다룰 '확인 질문'을 제안합니다.
3. **결정은 사람이 한다 (Human)**: AI가 도출한 리포트를 초안(v1)으로 삼아, 디자이너나 관리자가 검토/수정 후 최종 승인(v3)하여 리포트를 확정합니다.

---

## 🛠️ 개발 범위 및 단계별 계획 (Development Scope)

### Phase 1: 데이터 수집 및 통계 계산 로직 구현
- [ ] **Firestore 데이터 조회**: 분석 기간(예: 이번 주, 지난 주)에 생성되거나 상태가 변경된 모든 프로젝트의 핀(Pin) 데이터를 Fetch.
- [ ] **통계 데이터 산출 로직**: 
  - 신규 이슈 건수, 완료 건수, 재오픈(Re-open) 건수 계산.
  - 3일 이상 상태 변화 없는 방치된 이슈(Bottleneck) 추출.
  - 프로젝트별 미해결 이슈 비율 계산 (정체구간 프로젝트 선정).
- [ ] **데이터 전처리 (Privacy)**: 프롬프트에 들어가기 전, 민감한 개인정보(이름, 이메일 등)를 마스킹하거나 제거하는 유틸리티 함수 구현.

### Phase 2: Gemini API 연동 및 프롬프트 엔지니어링
- [ ] **서버 액션(Server Action) 생성**: `src/app/actions/qa-analytics.ts`를 생성하여 Gemini API 호출 비즈니스 로직 분리.
- [ ] **프롬프트 설계 (Prompting)**:
  - 시스템 역할 부여 (UX/QA 분석 전문가).
  - 입력 데이터 형식 정의 (마스킹된 QA 이슈 리스트).
  - 요구 출력 형식 정의 (반복 패턴 3가지, 근거 이슈 ID 매핑, 재오픈 원인 분석, 확인할 질문 제안).
- [ ] **JSON Schema 강제화**: `responseMimeType: "application/json"`을 활용하여 프론트엔드에서 바로 파싱 가능한 구조화된 응답(Structured Output) 획득.

### Phase 3: 프론트엔드 UI 개편 (AI 리포트 고도화)
- [ ] **새로운 리포트 레이아웃 적용**:
  - 시스템 통계 블록 (계산된 수치).
  - AI 발견 패턴 블록 (유형별 건수, 근거 이슈 ID, 상세 분석 내용).
  - 재오픈 원인 분석 블록.
  - 회의용 안건(확인할 질문) 제안 블록.
  - 휴먼 디시전(Human Decision) 기록 블록 (사람이 내린 결정, 담당자 지정란).
- [ ] **리포트 상태 관리 (버전 컨트롤)**:
  - 초안(v1 - Gemini 생성) ➡️ 수정본(v2 - 에디터 모드) ➡️ 승인본(v3 - DB 저장).
  - 기존 JSON 캐싱 방식을 넘어서, 확정된 리포트를 Firestore `ai_reports` 컬렉션에 저장하고 불러오는 로직 구현.

### Phase 4: 원본 데이터 연결 및 검증 기능
- [ ] **근거 이슈 ID 링킹**: AI가 뱉은 `QA-101`, `QA-108` 등의 근거 이슈 ID를 클릭하면, 실제 해당 프로젝트의 화면 핀 위치로 하이라이팅되며 이동하도록 라우팅 연결.
- [ ] **데이터 유효성 검사**: AI가 지어낸 허위 이슈 ID가 없는지, 시스템이 한 번 더 필터링(Validation)하는 로직 추가.

## 🚀 기대 효과 및 성과 측정 지표 (KPI)
- 주간 QA 보고서 작성 시간 단축 (수작업 대비).
- 동일 유형의 반복 QA 이슈 발생 감소율.
- 회의 준비 시간 감소 및 AI가 제안한 안건의 채택률(승인율).
