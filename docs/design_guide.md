# 디자인 가이드 (Design Guide)

## UI 프레임워크
- **shadcn/ui** 기반 컴포넌트를 사용하여 빠르고 일관된 디자인 시스템 적용.
- 전체적으로 심플하고 시선 분산이 적은 대시보드 형태의 레이아웃 유지.

## 핀(Pin) 마커 디자인
- 핀은 눈에 잘 띄는 색상(예: Red, Blue 등 상태나 우선순위에 따라 색상 분리 가능) 적용.
- 원형 마커 내부에 숫자를 기입하여 우측 리스트와 직관적 매핑.
- 화면 크기가 변해도 위치가 어긋나지 않도록 반드시 **X, Y 좌푯값을 퍼센트(%)** 로 렌더링.

## 상태값 (Status) 가이드
1. **이슈발생**: 신규 등록 상태 (회색 또는 빨간색 계열)
2. **확인/검토중**: 담당자가 확인 중인 상태 (노란색 계열)
3. **수정완료**: 개발이 완료되어 재검수가 필요한 상태 (파란색 계열)
4. **완료**: 검수까지 최종 통과한 상태 (초록색 계열)
5. **N/A (해당없음)**: 무시 또는 반려 상태

## 체크리스트(이슈 유형) 분류
- 레이아웃/간격
- 타이포그래피 (폰트/크기/굵기)
- 컬러/스타일 (오류/누락)
- 인터랙션/애니메이션
- 이미지/아이콘 (엑박/비율)
- 컴포넌트 동작 (버튼/탭/카드)
- 다국어/텍스트 깨짐
- 접근성 및 기타
