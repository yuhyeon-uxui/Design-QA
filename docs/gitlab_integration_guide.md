# 깃랩(GitLab) 양방향 연동 기획 (GitLab Integration)

## 📌 개요
디자인 QA 툴에서 생성된 이슈를 사내 GitLab 프로젝트로 내보내고(Sync), 반대로 GitLab에서 일어난 코드 수정 내역을 QA 툴로 당겨와 자동 알림을 띄우는 양방향 연동 플로우 기획입니다.

---

## 🛠 구현 현황 및 기능 명세

### 1. 멀티 플랫폼 및 사내망 지원 (현재 완료됨)
- **위치:** `src/components/GitHubSyncButton.tsx` (추후 IssueSyncButton으로 리팩토링 권장)
- **기능:**
  - 사용자가 GitHub와 GitLab 탭을 스위칭하여 원하는 플랫폼 연동 가능.
  - 온프레미스(사내망) 구축형 GitLab을 위해 **커스텀 도메인 주소** 입력 지원.

### 2. 프로젝트 리스트 자동 불러오기 (현재 완료됨)
- **기능:** 토큰(Token)을 입력하면 깃랩 API(`GET /api/v4/projects`)를 호출하여 해당 사용자가 권한을 가진 프로젝트 목록을 드롭다운 UI로 제공. (수동 입력 방지)

### 3. 디바이스 기반 자동 라우팅 (현재 완료됨)
- **기능:** 피그마 시안이 PC(Web)인지 Mobile(App)인지 식별(Device Type)하여, Web 이슈는 웹 깃랩 저장소로, App 이슈는 앱 깃랩 저장소로 **자동 분기(Routing)**하여 생성.

---

## 🚀 향후 고도화 계획 (Webhook 연동)

### 웹훅(Webhook) 기반 자동 알림 시스템
- 개발자가 깃랩에서 이슈 상태를 변경(Closed)하거나 코드를 Push할 경우, QA 툴 서버(`src/app/api/webhook/...`)로 웹훅을 전송.
- QA 툴은 웹훅을 받아 디자이너에게 인앱(In-App) 알림(🔔) 발송.

**연동 시나리오:**
1. **[QA 툴]** 디자이너가 이슈 등록 ➡️ 깃랩 이슈로 자동 복사 (Sync)
2. **[GitLab]** 개발자가 해당 이슈 코멘트에 `Fixes #이슈번호` 달고 코드 푸시
3. **[QA 툴]** 개발 완료 웹훅 수신 ➡️ 디자이너에게 "개발자가 코드 수정했습니다" 알림
4. **[QA 툴]** 디자이너가 재검수 후 반려(Re-open) ➡️ 깃랩 이슈 재오픈 및 개발자에게 알림
