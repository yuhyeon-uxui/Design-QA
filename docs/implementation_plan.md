# 구현 계획 (Implementation Plan)

## 1주차 MVP 마일스톤

- **1일차 (Day 1)**: 프로젝트/화면/이슈 DB 스키마 설계 및 기본 레포지토리 세팅 (Next.js, Tailwind, shadcn/ui).
- **2일차 (Day 2)**: 프로젝트 리스트 및 화면(캡처 이미지) 등록 CRUD 구현. Supabase Storage 연동.
- **3일차 (Day 3)**: 핵심 기능인 "이미지 위 핀 찍기" 구현. 디바이스 해상도 변경에도 유지되도록 X%, Y% 비율 기반 좌표계 적용.
- **4일차 (Day 4)**: 핀 번호와 매핑되는 이슈 작성/수정/삭제 폼 및 상태값 관리 기능 구현.
- **5일차 (Day 5)**: 테이블 형태의 이슈 리스트 뷰 및 팀별/상태별 필터 검색 기능 구현.
- **6일차 (Day 6)**: ExcelJS를 활용한 기존 QA 엑셀 포맷 다운로드 기능 구현.
- **7일차 (Day 7)**: UI 폴리싱, 테스트 및 Vercel 배포.

## 데이터베이스 스키마 요약
1. **Projects**: QA를 진행할 단위 (예: 메인 앱 디자인QA 1차)
2. **Screens**: 프로젝트에 속한 캡처 화면들 (이미지 URL 보관)
3. **Issues**: 화면 내 핀 위치(좌표)와 이슈 상세 내용(유형, 상태, 담당자 등) 보관
