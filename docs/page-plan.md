# 화면 구성 계획 (Page Plan)

## 1. 프로젝트 대시보드 (`/`)
- **역할**: 생성된 프로젝트 리스트를 보여주고, 전체 진행률 및 현황을 요약하는 화면
- **주요 요소**:
  - 프로젝트 생성 버튼
  - 프로젝트별 카드 뷰 (완료율, 남은 이슈 수, High 이슈 수 표시)

## 2. 화면별 QA 보드 (`/project/[id]/screen/[screenId]`) - **핵심 화면**
- **역할**: 실제 캡처 이미지를 보고 핀을 찍으며 이슈를 남기는 협업 공간
- **주요 요소**:
  - **좌측 영역 (Image Viewer)**: 캡처 이미지를 렌더링. 클릭 시 번호 핀 생성 및 위치 표기.
  - **우측 영역 (Issue List & Form)**: 핀 번호와 매핑되는 이슈 리스트 패널. 새로운 핀을 찍으면 입력 폼이 활성화됨.

## 3. 전체 이슈 리스트 뷰 (`/project/[id]/issues`)
- **역할**: 엑셀 형식에 익숙한 작업자들을 위해, 프로젝트 내 모든 이슈를 표 형태로 모아보는 화면
- **주요 요소**:
  - 테이블 형태의 데이터 그리드 (No, 핀 번호, 이슈 사항, 상태, 담당자 등)
  - 담당팀 필터, 상태 필터 (예: '수정 완료'만 보기, '디자인팀' 확인 필요 건만 보기)
  - 엑셀 내보내기 버튼
